# Support

## Documentation

- Start with the [repository README](README.md).
- See the [self-hosting guide](docs/self-hosting.md) for deployment and
  configuration.
- See the relevant application or package README for component-specific
  instructions.

## Questions and bug reports

Search [existing issues](https://github.com/circulo-ai/circulo/issues) before
opening a new one. Use a bug report for reproducible defects and a feature
request for product ideas. Include the Circulo version, operating system,
reproduction steps, expected behavior, and relevant sanitized logs.

Do not post credentials, personal data, private infrastructure details, or
security vulnerabilities in public issues. Follow the
[Security Policy](SECURITY.md) for security reports.

Community support is provided on a best-effort basis. This repository does not
provide a guaranteed response time or paid support service.
